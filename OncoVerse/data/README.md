# OncoVerse real data

The repository intentionally does not redistribute large Kaggle datasets. Run `python scripts/download_real_data.py <dataset>` after configuring Kaggle access.

Recommended public sources:

- Breast Cancer Wisconsin Diagnostic — Kaggle dataset `uciml/breast-cancer-wisconsin-data`
- Breast Cancer (METABRIC) — Kaggle dataset `gunesevitan/breast-cancer-metabric`
- BRCA Multi-Omics (TCGA) — Kaggle dataset `samdemharter/brca-multiomics-tcga`
- Lung and Colon Cancer Histopathological Images (LC25000) — Kaggle dataset `andrewmvd/lung-and-colon-cancer-histopathological-images`

Verify each dataset's current license and attribution requirements before redistribution.
