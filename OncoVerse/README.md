# 🧬 OncoVerse — Multi-Cancer Intelligence Platform

> A research-oriented cancer data engineering and AI platform combining multi-cancer evidence, machine learning, explainable AI, survival analysis, and interactive analytics.

## Overview

**OncoVerse** integrates cancer research evidence and real public datasets into a reproducible research platform. It includes ETL and data-processing workflows, XGBoost models, SHAP explainability, Kaplan–Meier and Cox survival analysis, a Streamlit dashboard, and a FastAPI research API.

The project separates published study-level evidence from independently trained patient-level models so that source-study findings and OncoVerse-generated results are not conflated.

## Key Features

- 🧬 Multi-cancer evidence exploration across eight CancerSEEK cancer types
- 🤖 XGBoost classification using public Wisconsin and METABRIC datasets
- 🔍 SHAP-based model explainability
- 📈 Kaplan–Meier and Cox proportional-hazards survival analysis
- 📊 Interactive Streamlit dashboard
- ⚡ FastAPI research API
- 🔄 ETL, normalization, and data-ingestion workflows
- 🔬 PubMed / clinical-trial discovery integrations
- 🏥 FHIR-oriented healthcare data integration
- 🧪 Automated tests with Pytest
- 🐳 Docker Compose support
- ☁️ Optional Airflow and Kafka orchestration components

## Datasets

### Breast Cancer Wisconsin Diagnostic

Used for benign-vs-malignant classification with an XGBoost model and held-out evaluation.

### METABRIC

Used for survival analysis and a derived 5-year research endpoint, including XGBoost classification, Kaplan–Meier analysis, Cox modeling, and concordance evaluation.

### CancerSEEK Evidence

Published study-level evidence covering eight cancer types is represented as benchmark/reference information. These published figures are kept separate from metrics generated by OncoVerse models.

Raw public datasets are intentionally not bundled in this repository. See `data/README.md` for the data workflow and download guidance.

## Results

Generated evaluation artifacts are available in `results/`, including:

- ROC curves
- Confusion matrices
- Classification reports
- SHAP feature-importance plots
- Kaplan–Meier curves
- ER-stratified survival curves
- Cox model results

The trained models and their evaluation metrics are stored in `models/real/`.

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

For development:

```bash
pip install -r requirements-dev.txt
```

## Run the Dashboard

After obtaining the required public datasets and following the instructions in `data/README.md`:

```bash
python -m streamlit run dashboard/app.py
```

## Train the Models

```bash
python scripts/train_real_models.py \
  --wisconsin data/raw/wisconsin/breast_cancer_wisconsin_diagnostic.csv \
  --metabric "data/raw/metabric/Breast Cancer METABRIC.csv"
```

## Run Tests

```bash
python -m pytest -q
```
