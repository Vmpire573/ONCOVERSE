# Results artifacts

This folder contains outputs from the active real-data presentation build.

- `pan_cancer_benchmark` — published CancerSEEK study-level cohort evidence; not an OncoVerse patient-level model.
- `wisconsin` — held-out Wisconsin Diagnostic XGBoost classification.
- `metabric_5y` — held-out METABRIC 5-year observed-follow-up endpoint.
- `metabric_survival` — held-out Cox C-index plus observed Kaplan–Meier analysis.

The active build does not use fabricated survival times or synthetic patient-level pan-cancer rows.
