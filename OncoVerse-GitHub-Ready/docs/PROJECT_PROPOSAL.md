# Project Proposal / Synopsis

## Title
**OncoVerse: AI-Powered Multi-Cancer Intelligence Platform for Research Data Integration and Explainable Analytics**

## Background
Cancer research data is distributed across heterogeneous public cohorts, biomarker studies and clinical research resources. A useful student research platform should integrate these sources while keeping data provenance and model claims explicit.

## Problem statement
Researchers need a reproducible workflow that combines multi-cancer evidence with real cohort analytics without presenting synthetic or inaccessible patient records as clinical data.

## Aim
Build a research platform that combines published multi-cancer evidence, real public cancer cohorts, ETL, explainable XGBoost modelling, survival analysis, an API and an interactive dashboard.

## Objectives
1. Represent an eight-cancer research scope using published CancerSEEK cohort evidence.
2. Integrate real Wisconsin Diagnostic and METABRIC cohorts.
3. Implement validation, normalization and provenance-aware ingestion.
4. Train and evaluate XGBoost research models on held-out data.
5. Provide SHAP explanations for trained models.
6. Implement observed survival analysis without fabricated follow-up times.
7. Provide a presentation-ready Streamlit dashboard and FastAPI interface.
8. Document limitations, provenance and responsible-use boundaries.

## Expected outcome
A locally runnable academic research platform that demonstrates multi-cancer evidence integration while maintaining a strict distinction between published study results and OncoVerse-generated model results.
